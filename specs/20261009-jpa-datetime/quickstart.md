# Quickstart & Validation Guide: JPA Date & Time Persistence

**Feature Directory**: `specs/20261009-jpa-datetime`  
**Subproject Location**: `persistence/spring-jpa-datetime`  
**Date**: 2026-10-09  

---

## 1. Prerequisites

- **JDK**: Java 17 or Java 21
- **Docker**: Docker Engine & Docker Compose (for running DB containers or Testcontainers)
- **Gradle**: Wrapper provided (`./gradlew`)

---

## 2. Automated Test Execution (Zero External Setup)

The project includes Kotest BDD tests leveraging Testcontainers for both MySQL and PostgreSQL.

### Run All Tests
```bash
cd persistence/spring-jpa-datetime
./gradlew test
```

### Expected Output
- MySQL container and PostgreSQL container spin up automatically.
- All 7 Java time types (`LocalDateTime`, `LocalDate`, `LocalTime`, `Instant`, `ZonedDateTime`, `OffsetDateTime`, `OffsetTime`) are inserted, fetched, and compared against raw DB column schemas.
- Test logs output comparison tables showing entity values vs physical DB string representations.
- REST API serialization tests verify ISO-8601 compliant JSON formatting.

---

## 3. Running with Docker Compose (Multi-App Multi-DB)

Run both MySQL and PostgreSQL along with two application instances simultaneously.

### Start All Services
```bash
cd persistence/spring-jpa-datetime
docker compose up -d --build
```

### Service Endpoints & Ports

| Service | Container / Port | Description |
|:---|:---|:---|
| **App 1 (MySQL Profile)** | `http://localhost:8080` | Connected to MySQL 8.4 (`spring.profiles.active=mysql`) |
| **App 2 (PostgreSQL Profile)** | `http://localhost:8081` | Connected to PostgreSQL 16 (`spring.profiles.active=postgres`) |
| **MySQL DB** | `localhost:3306` | User: `root` / `password: root`, DB: `tutorial` |
| **PostgreSQL DB** | `localhost:5432` | User: `postgres` / `password: postgres`, DB: `tutorial` |

## 4. Interactive Web UI Validation

1. Open **App 1 (MySQL)** in browser: `http://localhost:8080`
2. Open **App 2 (PostgreSQL)** in browser: `http://localhost:8081`
3. Click **"Create with Current Time (Asia/Seoul)"** or **"Create with Custom Timezone"**.
4. Observe the comparison view:
   - Formatted JSON response from the API.
   - Column types generated by Hibernate DDL.
   - Raw database string value stored in the database.
   - Restored entity values.

## 6. Curl Quick Validation Scenarios

### Create a Record
```bash
curl -X POST http://localhost:8080/api/time-records \
  -H "Content-Type: application/json" \
  -d '{
    "title": "KST Test Record",
    "localDateTime": "2026-10-09T08:30:00.123456",
    "localDate": "2026-10-09",
    "localTime": "08:30:00.123456",
    "instant": "2026-10-08T23:30:00.123456Z",
    "zonedDateTime": "2026-10-09T08:30:00.123456+09:00[Asia/Seoul]",
    "offsetDateTime": "2026-10-09T08:30:00.123456+09:00",
    "offsetTime": "08:30:00.123456+09:00"
  }'
```

### Inspect Raw DB Mapping
```bash
curl http://localhost:8080/api/time-records/{id}/db-raw
```
