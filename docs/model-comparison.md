## 2. 작업 특성별 모델 선택 가이드

### ① 대규모 아키텍처 및 복잡한 비동기 코딩 (예: SSE 스트리밍 멀티모듈 구현)
- **추천**: **`Claude Sonnet 5.5` (Effort: Medium)** 또는 **`Gemini 4 Argon`**
- **이유**:
  - WebFlux, Netty 이벤트 루프, Kotlin Coroutine Flow 취소 전파, Java 21 Virtual Thread Pinning 방지 등 미묘한 동시성 제어가 필요한 작업은 상위 모델을 써야 턴 낭비(Trial and Error) 없이 한 번에 통과합니다.
  - Opus 5.5는 Output 비용이 $75로 매우 비싸 코딩 작업에는 비효율적입니다.

### ② 일상적인 기능 추가, 리팩토링 및 테스트 작성
- **추천**: **`Gemini 4 Neon`** 또는 **`Claude Sonnet 5.5` (Effort: Low)**
- **이유**: 일반적인 CRUD, 단위 테스트, DTO 매핑 등은 1M당 $1 내외의 모델로도 충분히 높은 품질을 얻을 수 있습니다.

### ③ 단순 문서화, 설정 검토, 파일 정리
- **추천**: **`Gemini 3.8 Flash`** 또는 **`Gemini 4 Hydrogen`**
- **이유**: 가장 빠르고 비용 부담 없이 대량의 파일 검색 및 단순 수정을 처리할 수 있습니다.
